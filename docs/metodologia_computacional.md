# Metodologia computacional

- MCN: arts. 17–21 independentes, sem score global.
- IAL: 40/35/25 como cenário de teste, com cobertura completa/parcial/não calculável.
- Proteção: quatro fontes progressivas, sem score.
- Priorização: camadas A–E, ordem lexicográfica explicável, parâmetro N e validação humana.
- Reavaliação: comparação automática permitida; persistência fundamentada é análise profissional.
- CRPS: categoria profissional com checklist; jamais derivada do IAL.

# Modelo de dados

Entidades: estudantes, ciclos, benefícios, histórico acadêmico, parâmetros curriculares, disciplinas obrigatórias, taxas de turma, integralização, MCN, IAL, fatores de proteção, acompanhamentos, histórico de avaliações, priorização, distribuição, contextualização, atendimentos, MAIC, MNA, PIAAP/ações, manutenção, monitoramento, reavaliação, CRPS, pareceres, notificações, recursos, Comissão, usuários e logs.

GRR identifica o estudante; tabelas transacionais possuem IDs próprios para preservar múltiplos registros e temporalidade.
